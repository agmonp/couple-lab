Couple Lab קוד המקור ב־GitHub

רגע שקט לשיחה טובה יותר ביניכם

Couple Lab היא אפליקציה לזוגות: בוחרים שאלה, מקיימים שיחה מונחית, ומקבלים סיכום עדין. הכול רץ על המחשב שלכם, ושום דבר לא עולה לאינטרנט.

הורדה ל־Windows איך מתקינים

חינם · קוד פתוח (MIT) · ל־Windows 10 ו־11 (64 ביט)

מה יש בפנים

חפיסות שאלות

תשע חפיסות של שאלות לשיחה, בהשראת גוטמן, שעוזרות להתקרב ולהכיר מחדש.

שיחות מונחות

שיחה צעד אחר צעד: אחרי ריב, או כשאחד מכם עמוס וצריך הקשבה. יש תורות ברורים וזמנים.

הקלטה ותמלול בעברית

אם שניכם מסכימים, השיחה מוקלטת ומתומללת. בסוף רואים מי דיבר כמה ואילו רגעים חשובים עלו.

פרטי לגמרי

אין חשבון ואין שרת. ההקלטות, התמלולים והסיכומים נשמרים רק במחשב שלכם, ואפשר למחוק אותם בכל רגע.

Couple Lab היא כלי לתרגול, לא טיפול זוגי ולא אבחון. היא לא שופטת מי צודק. אם יש פגיעה או סכנה, פנו לאיש מקצוע.

התקנה, שתי דקות

  1. מורידים את הקובץ Couple-Lab-Windows.exe מהכפתור למעלה.
  2. פותחים אותו בלחיצה כפולה. אין התקנה. זו תוכנה ניידת שרצה ישירות מהקובץ, ואפשר לשמור אותה בכל תיקייה.
  3. אם Windows מציג "Windows protected your PC", לוחצים על More info ואז על Run anyway. ההודעה מופיעה כי התוכנה עדיין לא חתומה דיגיטלית.
  4. מאשרים מצלמה ומיקרופון כשהאפליקציה מבקשת. כל אחד מכם נרשם בתורו, ואז אפשר להתחיל שיחה ראשונה.

תמלול עברית מדויק (רשות, למתקדמים)

הגרסה הניידת מתמללת עם מנוע קטן ומהיר. זה מספיק לסיכום, אבל לא מדויק בעברית. כדי לקבל תמלול טוב בהרבה (מודל ivrit-ai שרץ אצלכם במחשב), מריצים את האפליקציה מקוד המקור. עדיף מחשב עם כרטיס מסך NVIDIA. בלי כרטיס כזה זה עובד, אבל לאט יותר.

הוראות התקנה מקוד המקור

צריך Node.js 20+, Python 3.11 ו־Git. אחר כך ב־PowerShell:

git clone -b local-hebrew https://github.com/agmonp/couple-lab.git
cd couple-lab
npm install
powershell -ExecutionPolicy Bypass -File .\scripts\install-hebrew-asr.ps1
npm run desktop:run

ההתקנה מורידה פעם אחת מודל של כ־1.6GB. את קובצי המודלים הקטנים (תיקיית models) לוקחים מתוך הגרסה הניידת, או לפי models/README.md.
